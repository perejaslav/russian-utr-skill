## Одно действие — одно обозначение

Выберите одно слово из строки и используйте его во всём тексте. Правило
`synonym-rotation` сравнивает файл целиком.

| Понятие | Синонимы |
| --- | --- |
| проверка | `проверить`, `валидировать`, `верифицировать`, `контролировать` |
| удаление | `удалить`, `стирать`, `стереть` |
| запуск | `запустить`, `стартовать` |
| остановка | `остановить`, `прекратить` |
| показ | `показать`, `отобразить` |
| использование | `использовать`, `применять`, `задействовать` |
| исправление | `исправить`, `устранить`, `починить` |
| отправка | `отправить`, `передать`, `отсылать` |
| получение | `получить`, `извлечь` |
| изменение | `изменить`, `модифицировать`, `править` |
| уведомление | `сообщить`, `уведомить` |
| настройка | `настроить`, `конфигурировать` |
| подключение | `подключить`, `присоединить` |
| поиск | `найти`, `обнаружить` |

Пример. Оставляем слово «проверить»:

```text
✗ Проверьте конфигурацию. Затем валидируйте ответ.
✓ Проверьте конфигурацию. Потом проверьте ответ.
```

Пример. Оставляем слово «удалить»:

```text
✗ Удалите кэш. Затем сотрите журнал.
✓ Удалите кэш. Потом удалите журнал.
```

## Термины, которые нужно объяснить

Новый термин объясняют при первом употреблении. Повторять объяснение не нужно.

| Термин | Объяснение в одном предложении |
| --- | --- |
| таймаут | Предельное время ожидания ответа. |
| идемпотентность | Повторный запрос даёт тот же результат, что и первый. |
| дедлайн | Крайний срок сдачи работы. |
| кэш | Копия данных, которую сервер хранит для быстрого ответа. |
| дрейф конфигурации | Расхождение между файлом и настройками на сервере. |

## Как пополнить словарь проекта

1. Выпишите термины, которые читатели понимают по-разному.
2. Выберите одно слово для каждого термина.
3. Добавьте строку в таблицу «Одно действие — одно обозначение».
4. Не добавляйте синонимы. Один термин — одно слово.
