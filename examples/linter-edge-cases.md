# Краевые случаи линтера

В этом файле специально сделаны ошибки в структуре Markdown. Файл нужен, чтобы
проверить линтер руками. Это фикстура, а не образец текста УТР.

Проверка даёт две находки правила `dangling-conjunction` в строках 14 и 15.

```bash
python scripts/utr-lint.py examples/linter-edge-cases.md
```

## Код в блоке

Команда ниже содержит точку с запятой и канцеляризм. Линтер не проверяет код.

~~~text
python -m build --wheel; в целях контроля проверьте журнал
~~~

## Блок кода с обратными кавычками

```bash
docker compose up -d; в целях контроля проверьте журнал
```
